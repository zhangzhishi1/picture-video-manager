# 图片与视频管理 / Image & Video Manager

思源笔记插件：以**链接 / 导入资源**两种模式集中管理图片与视频。

## 版本与订阅

基础版永久免费，包含单条媒体管理、搜索筛选与三种视图、标签/评分/说明/文档关联，以及单条外链或资源导入。

高级版包含批量资源导入与本地引用、目录挂载与自动重扫、批量拍摄时间识别和 GPS 地理位置识别。

- 半年订阅：19.9 元（183 天）
- 一年订阅：30 元（365 天）

授权码仅保存在插件本地数据中。插件启动时进行一次联网状态复查；网络不可用时，以本地 Ed25519 验签结果继续工作。激活、吊销或过期状态以授权服务响应为准。

## 功能

- 双模式：外链管理，或导入资源到工作空间（按 `年/月/日` 层级存储）
- 三视图：缩略图（大小可调）、列表、详情放大，点击任意缩略图进入 lightbox
- 自动识别拍摄日期（文件名 / URL），自动打标签，支持自定义标签
- Markdown 说明，一键复制链接、一键复制「图片/视频 + 说明」的 Markdown
- 星级评分、按类型/标签/月份筛选、多字段排序
- 关联思源文档（block-ref 原生悬浮预览 + 点击打开）
- 缩略图缓存保存到 `storage/petal/picturevideomanager/cache/thumbs`，可在设置中查看大小并清理

## 开发

```bash
npm install
npm run check   # tsc 类型检查
npm run dev     # 开发监听
npm run build   # 生产构建，产出 dist/ 与 package.zip
```

## 部署

`npm run build` 后，把 `dist/` 整个目录拷贝到：

```
工作空间/data/plugins/picture-video-manager/
```

再在思源「设置 - 集市 - 已下载」中重载插件即可。
