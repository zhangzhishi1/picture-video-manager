# 图片与视频管理 / Image & Video Manager

思源笔记桌面端插件，集中管理**外链、工作空间资源和本地引用**形式的图片与视频。需要思源笔记 **3.7.0 或以上版本**，支持 Windows、macOS 和 Linux 桌面端。

### 激活高级版

1. 打开媒体管理界面，点击“设置”。
2. 复制“本机码”，购买时提供给授权签发方。
3. 将收到的完整授权码粘贴到“授权码”输入框，联网点击“激活”。成功后当前已打开的媒体界面立即解锁，无需重启。
4. “保存”用于保存高德 Key；激活操作单独即时保存，不需要再次点击“保存”。

授权服务为 `https://api.aixuexibook.online`。客户端先校验 Ed25519 签名、插件归属、版本、设备绑定及有效期；每次插件加载仅联网复查一次，不在使用高级功能时重复请求，也不进行定时轮询。

- **首次激活需要联网成功**。网络异常不会保存新授权码，请恢复网络后重试。
- **已激活授权启动时离线**：本地验签和有效期仍通过时继续使用，并在设置中标注离线验证；本地已到期的授权不会因断网恢复。
- 服务明确返回过期、吊销、授权不存在或设备不匹配时会降级，设置页展示原因。运行期间的远程变更最迟在重载插件或重启思源后的启动检查生效。
- 纯日期有效期按**上海时间**计算，到期当天有效；带时区的时间戳按精确时刻计算，界面转换为本地可读时间。
- “取消本机激活”只清除本地授权，不吊销服务端授权，不删除媒体记录，并保留本机码；再次激活需要重新输入授权码。
- 授权失效不清空已有媒体、挂载配置或地理信息。基础版仍可浏览、编辑普通信息和删除已有条目，但不能新增或修改本地引用来源、重扫或执行高级批量操作。

### 授权与隐私

授权信息使用插件私有数据保存，不写入媒体库导出数据。机器码由本地持久化随机源经 SHA-256 摘要生成；授权请求仅发送授权序号 `serial` 和摘要后的 `machine`，不上传媒体文件、原始随机源、MAC 或本机文件路径。

本机码随插件私有数据保留；如果删除、复制或同步整份插件授权数据，本机码也可能重置或随之迁移，不等于硬件指纹。换机、重装或清除数据前请联系签发方确认迁移规则，不要向他人分享授权数据。

## 功能

- 双模式：外链管理，或导入资源到工作空间（按 `年/月/日` 层级存储）
- 三视图：缩略图（大小可调）、列表、详情放大，点击任意缩略图进入 lightbox
- 自动识别拍摄日期（文件名 / URL），自动打标签，支持自定义标签
- Markdown 说明，一键复制链接、一键复制「图片/视频 + 说明」的 Markdown
- 星级评分、按类型/标签/月份筛选、多字段排序
- 关联思源文档（block-ref 原生悬浮预览 + 点击打开）
- 缩略图缓存保存到 `storage/petal/picturevideomanager/cache/thumbs`，可在设置中查看大小并清理

## 使用说明

### 媒体来源

- **链接**：仅记录外链 URL，不复制原文件；显示依赖网络和来源站点权限。
- **资源**：单条或批量导入思源工作空间，按年／月／日组织；工作空间备份时请一并备份资源。
- **本地引用（高级版）**：不复制源文件，保留本机绝对路径。仅适合当前桌面设备，文件移动、磁盘未挂载或跨设备使用时可能不可访问。
- **目录挂载（高级版）**：递归扫描目录中的图片与视频，按相对目录生成媒体库文件夹；解除挂载不删除磁盘源文件。

删除时请区分“仅移除记录”和“同时处理源文件”，以确认框列出的范围为准。删除记录不等于备份，操作源文件前请另行备份。

### GPS 与高德 Key

在设置中填写高德开放平台的 **Web 服务 Key**，需要包含基础服务／逆地理编码能力。Key 仅保存在当前插件数据中，默认密文显示。高级版可对全库、当前页或单张图片识别位置；仅含有效 EXIF GPS 的图片能够转换为省市区与地点，无 GPS 的图片不会凭空推断位置。调用高德时会向高德服务发送坐标和 Key，第三方额度与权限以高德规则为准。

### 数据与缓存

媒体索引、设置及授权位于思源工作空间的插件私有数据中；缩略图是可再生成缓存，清理不会删除原始媒体。备份工作空间时，除资源和插件数据外，本地引用及挂载目录中的源文件需要另外备份。

## 开发

```bash
npm install
npm run check   # tsc 类型检查
npm test        # 授权解析、有效期、生命周期与门禁回归测试
npm run dev     # 开发监听
npm run build   # 生产构建，产出 dist/ 与 package.zip
```

## 源码备份

运行 `npm run backup`，在 `backups/` 生成带时间戳和随机后缀的源码压缩包及 SHA-256 校验文件，不覆盖历史备份。备份包含源码、配置、依赖锁文件和静态资源，排除依赖安装目录、构建产物、图谱缓存及 macOS 元数据。

恢复时先在备份目录运行 `shasum -a 256 -c <压缩包名>.sha256`，校验通过后将压缩包解压到独立目录，再运行 `npm ci` 安装依赖。此工具只备份项目源码，不包含思源工作空间中的媒体库、挂载源文件或插件业务数据。

## 部署

`npm run build` 后，把 `dist/` 整个目录拷贝到：

```
工作空间/data/plugins/picturevideomanager/
```

再在思源「设置 - 集市 - 已下载」中重载插件即可。

安装目录必须与插件清单的 `name`（`picturevideomanager`）一致。构建只更新磁盘产物，不会替换思源中已加载的实例；测试新的授权初始化逻辑时，必须禁用后重新启用插件或重启思源。
