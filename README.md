# 图片与视频管理

把分散的图片和视频整理到思源笔记中，方便浏览、分类、查找和引用。

无论是网上收藏的图片、工作空间中的素材，还是电脑和移动硬盘里的照片与视频，都可以在同一个媒体库中管理。

适用于 **思源笔记 3.7.0 及以上版本**，支持 **Windows、macOS 和 Linux 桌面端**。

## 主要功能

### 多种方式收集素材

- **添加外链**：收藏网络图片或视频链接，不必下载原文件。
- **导入资源**：将媒体文件保存到思源工作空间，便于与笔记一起整理。
- **本地引用（高级版）**：直接管理电脑或移动硬盘里的媒体，不额外复制文件。
- **目录挂载（高级版）**：扫描指定文件夹及其子文件夹，将其中的图片与视频加入媒体库。

### 按习惯浏览和查找

- 提供**缩略图、列表、详情**三种视图，适合快速浏览或查看详细信息。
- 缩略图大小可调，支持放大查看图片、预览视频。
- 支持文件夹分类、自定义标签和星级评分。
- 通过关键词搜索，结合媒体类型、标签、月份筛选和多种排序方式，更快找到需要的素材。

### 让素材与笔记相连

- 为图片和视频添加说明，记录背景、用途或灵感。
- 一键复制媒体的 Markdown 链接，也可连同标签和说明一起复制，方便粘贴到笔记中。
- 填写思源文档或块的 ID 后，可关联对应笔记，悬浮预览或点击打开。

### 整理拍摄时间与地点

- 支持识别拍摄日期，方便按月份查找；高级版可批量重新识别拍摄日期与时间。
- **位置识别（高级版）**：将照片自带的定位信息转换为地点名称，方便整理旅行、生活和采集素材。
- 可在设置中查看并清理缩略图缓存，清理缓存不会删除原始图片和视频。

> 日期识别结果可能与真实拍摄时间不同，建议整理后核对。位置识别需要照片本身带有有效定位信息，并在设置中填写高德 Web 服务 Key；没有定位信息的照片不会自动推测地点。

## 快速上手

1. 在思源中启用插件，打开图片与视频管理界面。
2. 添加一个媒体链接，或选择文件导入工作空间。
3. 按需要设置分类、标签、评分和说明。
4. 使用搜索、筛选或不同视图浏览素材，将需要的媒体复制到笔记中。

素材较多时，可使用高级版批量导入或挂载目录。挂载后如有新增、移动或删除文件，请手动点击“重扫”更新，**不会在后台自动同步目录变化**。

### 激活高级版

1. 打开插件“设置”，复制“本机码”。
2. 购买授权并提供本机码。
3. 将收到的完整授权码粘贴到“授权码”输入框，联网点击“激活”。
4. 激活成功后即可使用高级功能，无需重启，也无需再次点击“保存”。

首次激活需要联网。已激活且本地验证仍有效的授权，在启动时遇到网络异常可继续离线使用；过期或失效的授权不会因此延长有效期。订阅失效不会清空已有媒体记录，仍可使用基础版功能。

## 使用提醒

- **外链素材**依赖网络和来源网站权限，链接失效后可能无法预览。
- **本地引用**不会将源文件复制到思源中。文件移动、硬盘断开或换设备后，原引用可能无法访问；不保证跨设备可用。
- **解除目录挂载**不会删除磁盘上的源文件。
- **删除素材前**请看清确认提示，区分仅移除记录和同时处理源文件，重要素材请先备份。
- **视频预览与封面**受系统及视频格式支持情况影响，不同设备上的表现可能不同。
- **工作空间备份**应包含媒体资源和插件数据；本地引用与挂载目录中的源文件需要另外备份。
- **位置识别**会向高德服务发送照片坐标及所配置的 Key，服务额度和使用权限以高德规则为准。
- **授权激活与检查不会上传媒体文件**。请勿分享授权数据，换机、重装或清除插件数据前，请先联系授权签发方确认迁移方式。
